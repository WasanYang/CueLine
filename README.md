# SongSections

หาท่อนเพลงจากลิงก์ YouTube หรือไฟล์เสียง แล้ว export เป็นไฟล์ MIDI ที่มี marker และ tempo สำหรับเปิดใน Logic Pro
(ส่วนคอร์ด ให้ใช้ Chord ID ของ Logic)

## ติดตั้ง
```
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```
แนะนำให้ติดตั้ง Deno ด้วย (`winget install DenoLand.Deno`) เพราะ yt-dlp ใช้ Deno ดึงข้อมูลจาก YouTube ถ้าไม่มี อาจได้ไฟล์เสียงคุณภาพไม่ครบ

ใช้ [all-in-one-infer](https://github.com/openmirlab/all-in-one-infer) ซึ่งเป็น fork ของ All-In-One ที่ไม่ต้องใช้ NATTEN จึงรันบน Windows ได้ ใช้น้ำหนักโมเดลชุดเดียวกับต้นฉบับ (MIT)

allin1 หา downbeat ได้ด้วย บาร์ใน Logic จึงจะตรงกับห้องของเพลง

```
.venv\Scripts\python run_web.py
```

- วางลิงก์ YouTube หรือเลือกไฟล์เพลง แล้วกด **วิเคราะห์** (ถ้าใช้ allin1 เพลงยาว 8 นาทีใช้เวลาประมาณ 5 นาที)
- **แก้ท่อน**
  - ลากขอบแถบสีเพื่อย้ายจุดเปลี่ยนท่อน ขอบจะเกาะห้องหรือบีตตามที่ตั้ง "สแนป" ไว้
  - กด ✂ หรือ S เพื่อตัดท่อนตรงตำแหน่งที่เล่นอยู่
  - กด ⨯ เพื่อรวมกับท่อนก่อนหน้า
  - แก้ชื่อในตารางได้
- **โครงเพลงและเนื้อร้อง**: วางเนื้อเพลงที่มีชื่อท่อนในวงเล็บเหลี่ยม เช่น `[Intro]`, `[V1]`, `[Chorus x2]`, `[Bridge]` แล้วกด "จัดท่อนตามโครงนี้" ระบบจะใช้ชื่อและลำดับท่อนตามที่ใส่ แล้วหาจุดเริ่มของแต่ละท่อนจากผลวิเคราะห์ ระหว่างเล่นเพลงจะแสดงเนื้อของท่อนที่กำลังเล่น
- **รวมท่อนซ้ำ**: รวมท่อนชื่อเดียวกันที่อยู่ติดกัน เช่น Chorus 4–12 จะกลายเป็นท่อนเดียว
- **Export .mid**: ได้ไฟล์ MIDI สำหรับเปิดใน Logic ส่วนไฟล์เพลงดาวน์โหลดได้จากเมนู ⋯
- **โหมดเล่นสด** (ปุ่ม "▶ โหมดเล่นสด" หรือเปิด `live.html`)
  - ปุ่มท่อนเพลง: กดเพื่อกระโดดไปท่อนนั้น ตั้งได้ว่าจะกระโดดทันที เมื่อจบห้อง หรือเมื่อจบท่อน
  - Click: เคาะตาม beat ของเพลง ห้องแรกเน้นเสียง
  - Guide: พูดชื่อท่อนถัดไปในห้องก่อนเปลี่ยนท่อน ใช้เสียงคิวจากโฟลเดอร์ `cues/` (ดูหัวข้อ "เสียงคิว") ถ้าไม่มีไฟล์จะใช้เสียงอ่านของ browser
  - วนท่อนได้ และนับ 1 ห้องก่อนเริ่มเล่นได้
  - ปิดเสียงเพลงได้ ถ้าจะใช้แค่ click
  - ปุ่มลัด: Space = เล่น/หยุด, 1–9 = กระโดดไปท่อน, L = วนท่อน, C = เปิด/ปิด click, ← → = ท่อนก่อน/ถัดไป
- เลขบาร์ที่แสดงบนหน้าเว็บตรงกับเลขบาร์ที่ Logic จะแสดงหลังเปิดไฟล์ .mid
- เพลงทั้งหมดเก็บอยู่ในโฟลเดอร์ `library\`

## เสียงคิว (cues/)
โปรเจกต์นี้ไม่ได้แถมไฟล์เสียงคิวมาให้ ต้องหาเองแล้ววางไฟล์ `.wav` ไว้ในโฟลเดอร์ `cues/` ซึ่ง git ไม่ติดตามไฟล์ในโฟลเดอร์นี้
- **ชื่อท่อน**: `intro`, `verse`, `prechorus`, `chorus`, `bridge`, `solo`, `instrumental`, `turn` (ใช้กับ Midtro/Turnaround), `break`, `outro`, `end`, `tag`, `keychange`, `acapella`, `band`, `riff`
- **ตัวเลข**: `1`–`7` ใช้ทั้งนับก่อนเริ่มเพลงและนับ "3, 4" ก่อนเข้าท่อน
- **เสียง click (ไม่ใส่ก็ได้)**: `click-hard`, `click-soft` เป็นไฟล์ click ยาว 1 ห้อง 4 จังหวะ ระบบจะตัดเอาจังหวะแรกเป็นเสียงเน้น

ชุดที่ทดสอบแล้วคือ "Clicks and Cues" ของ Worship Tutorials ซึ่งแจกฟรี ใช้ได้แค่ในเครื่องตัวเอง เงื่อนไขห้ามแจกต่อ ห้ามเอาขึ้นเรโป และห้ามรวมไว้กับแอปที่ให้คนอื่นดาวน์โหลด

จังหวะการพูดในห้องก่อนเปลี่ยนท่อน
- ชื่อท่อนเริ่มที่จังหวะ 1 ถ้าเป็น Verse จะตามด้วยเลขท่อน
- นับ "3, 4" ตรงจังหวะ 3 และ 4 พอดี
- ถ้าเพลงเร็วจนพูดชื่อท่อนไม่ทัน จะเริ่มพูดเร็วขึ้นเล็กน้อย เพื่อให้จบก่อนนับ 3

## ใช้งานผ่าน command line
```
.venv\Scripts\python -m songsections "<ลิงก์ YouTube หรือไฟล์เสียง>"
```
ไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์ `output\`
- ไฟล์ `.mp3` คือเพลงสำหรับลากเข้า Logic
- ไฟล์ `.mid` คือ marker ท่อนเพลงกับ tempo
- ไฟล์ `.json` คือผลวิเคราะห์ทั้งหมด

ตัวเลือกที่ใช้บ่อย
- `--groups N` บังคับจำนวนท่อนที่ต่างกัน (ค่าเริ่มต้นให้ระบบเลือกเอง)
- `--min-bars N` ความยาวท่อนสั้นสุด (ค่าเริ่มต้น 2 บาร์)
- `--tempo-mode constant` ใช้ tempo เดียวทั้งเพลง แทนการไล่ตามทุก beat

## เปิดใน Logic Pro
1. ใช้ **File > Open** เปิดไฟล์ `.mid` ห้ามใช้ Import เพราะ Import จะไม่เอา tempo และ marker มาด้วย
2. ลากไฟล์ `.mp3` ใส่ที่บาร์ 1 ถ้า Logic ถามว่าจะปรับ tempo หรือ time-stretch ไฟล์เสียง ให้เลือกไม่ปรับ
3. ถ้าต้องการ Arrangement Marker ให้ใช้คำสั่ง Convert to Arrangement Markers ในเมนูของ Marker track

## ข้อจำกัด
- ชื่อ marker จะอยู่ในรูป `Chorus 1 [C]` ตัวอักษรในวงเล็บคือกลุ่ม ท่อนที่มีตัวอักษรเดียวกันคือท่อนที่เสียงคล้ายกัน ส่วนชื่อท่อน (Verse/Chorus) เป็นการเดาจากการซ้ำและความดัง
- ถ้าใช้วิธี librosa: ชื่อท่อนเป็นการเดา ถือว่าเพลงเป็น 4/4 เสมอ และไม่ได้หาจังหวะแรกของห้อง ทำให้บาร์อาจไม่ตรงกับห้องของเพลงจริง
