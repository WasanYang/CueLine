    เพลงของฉัน

      ยังไม่มีเพลง ลองวางลิงก์ YouTube ด้านบน

      หาท่อนเพลง แล้วส่งเข้า Logic Pro

      วางลิงก์ YouTube หรือเลือกไฟล์เพลง ระบบจะหา Intro, Verse, Chorus และท่อนอื่น ๆ ให้ ตรวจและแก้ได้ที่นี่ แล้ว export เป็นไฟล์ .mid ที่มี marker

      ▶ โหมดเล่นสด
      ⋯
      ดาวน์โหลดไฟล์เพลง
      0:00.0
      กำลังโหลดคลื่นเสียง…

      ลากขอบแถบสีเพื่อย้ายจุดเปลี่ยนท่อน · คลิกบนคลื่นเสียงเพื่อไปตำแหน่งนั้น · Space = เล่น/หยุด · S = ตัดท่อน

      โครงเพลงและเนื้อร้อง

      ใส่ชื่อท่อนในวงเล็บเหลี่ยม เช่น [V1] หรือแบบ chord sheet เช่น Verse 1: แล้วตามด้วยเนื้อร้อง ท่อนดนตรีไม่ต้องมีเนื้อร้องก็ได้

      วาง chord sheet ทั้งชุดได้เลย ระบบจะตัดบรรทัดที่มีแต่คอร์ด และตัวย่อหน้าบรรทัด เช่น 1: C: ออกให้ (คอร์ดให้ Chord ID ใน Logic จัดการ)

      ชื่อที่ระบบรู้จัก: Intro · V / Verse · Pre / Pre-Chorus · C / Chorus / Hook / ฮุก · B / Bridge · Solo · Inst / Interlude / Midtro · Break · Outro / Ending ใส่ x2 ต่อท้าย เช่น [Chorus x2] ถ้าท่อนนั้นซ้ำติดกัน ชื่ออื่นจะใช้ตามที่พิมพ์

      ระบบจะเรียงท่อนตามลำดับนี้ลงบนจุดเปลี่ยนที่วิเคราะห์ได้ โดยเลือกจุดที่ชนิดท่อนตรงกันที่สุด จากนั้นลากขอบปรับต่อได้ และกด บันทึก เมื่อพอใจแล้ว

      ยังไม่มีเนื้อเพลง? ให้ระบบแยกเสียงร้องแล้วถอดเป็นข้อความ (ทดลอง) ผลเป็นแค่ร่าง ต้องตรวจแก้เองเสมอ เนื้อที่ได้จะใส่ลงท่อนตามเวลาที่ร้อง
